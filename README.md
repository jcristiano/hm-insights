# HomeBank Insights

Aplicação web interativa para análise e agrupamento **completo (100%)** de categorias de arquivos do **HomeBank** (`.xdb` / `.xml`).

## 🚀 Como Executar

1. Descompacte o arquivo ZIP baixado.
2. Abra o terminal na pasta do projeto.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra o link exibido no terminal (geralmente `http://localhost:5173`) no seu navegador.
